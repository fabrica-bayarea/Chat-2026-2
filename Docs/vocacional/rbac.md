# Controle de Acesso - Teste Vocacional

## 1. Objetivo

Este documento apresenta como funciona o acesso às funcionalidades do teste vocacional e quais ações estão disponíveis para o usuário.

Atualmente, o teste possui apenas as funções necessárias para sua realização. Não existe uma área administrativa própria para alterar as informações diretamente pelo sistema.

## 2. Perfil de Acesso

### 2.1 Usuário

O usuário é a pessoa que utiliza o teste vocacional para conhecer cursos que podem ter relação com seu perfil.

Ele pode iniciar o teste, responder às perguntas, informar suas preferências e visualizar o resultado apresentado ao final.

## 3. Permissões

| Ação | Usuário |
|---|---|
| Iniciar o teste vocacional | Sim |
| Responder às perguntas | Sim |
| Informar modalidade de ensino | Sim |
| Visualizar o resultado | Sim |
| Alterar perguntas e alternativas pelo sistema | Não |
| Alterar cursos e modalidades pelo sistema | Não |
| Alterar os perfis utilizados pelo teste | Não |

## 4. Considerações sobre o Acesso

No estado atual do projeto, alterações nas perguntas, perfis, cursos e outras informações internas são feitas diretamente no desenvolvimento do sistema, e não por uma área administrativa.

Caso uma área de administração seja criada futuramente, novos perfis e permissões poderão ser adicionados a este documento.
