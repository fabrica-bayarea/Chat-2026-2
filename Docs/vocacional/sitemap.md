# Sitemap - Teste Vocacional

## 1. Objetivo

Este documento apresenta a organização das principais etapas do teste vocacional e mostra o caminho que o usuário percorre desde o início até a visualização do resultado.

A ideia é deixar de forma simples como as partes do teste se conectam e em qual ordem são acessadas.

## 2. Estrutura do Teste

O fluxo principal do teste vocacional é organizado da seguinte forma:

- Início do teste
  - Apresentação do teste
  - Início das perguntas

- Perguntas
  - Exibição das perguntas
  - Escolha das alternativas
  - Registro das respostas

- Preferências
  - Escolha da modalidade de ensino
  - Verificação das opções disponíveis

- Resultado
  - Cálculo dos perfis
  - Identificação dos perfis com maior compatibilidade
  - Apresentação dos cursos relacionados ao resultado

  ## 3. Fluxo de Navegação

O caminho principal percorrido pelo usuário pode ser representado da seguinte forma:

Início → Perguntas → Escolha da modalidade → Cálculo do resultado → Cursos recomendados

## 4. Observações

O sitemap representa o fluxo principal do teste vocacional. Caso novas etapas ou funcionalidades sejam adicionadas futuramente, essa estrutura poderá ser atualizada para acompanhar as mudanças do sistema.
