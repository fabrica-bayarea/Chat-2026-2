# EP-06 — Histórico do Usuário

**Descrição:** Permite ao usuário cadastrado consultar os testes vocacionais que já concluiu, do mais recente para o mais antigo, e refazer o teste sem perder os resultados anteriores. Depende de [EP-05](EP-05.md) (autenticação).

**Personas:** Usuário Cadastrado.
**Protótipo:** https://www.figma.com/design/GjWpxDN4CeaC00N0Rgvrs6/chatbot?node-id=15-2&p=f&t=aDqX7Pxi2gM39kXH-0

## US-01 — Ver testes anteriores

Como usuário cadastrado, quero ver os testes que já fiz, para acompanhar
minha evolução ou comparar resultados ao longo do tempo.

- **RF-11**: o sistema deve listar, para o usuário autenticado, todas as
  sessões de teste concluídas vinculadas à sua conta, da mais recente para a
  mais antiga.
- **CA-07**: dado um usuário cadastrado com 2+ testes concluídos, quando
  acessa `/historico`, então vê as duas sessões listadas com data e perfil
  predominante de cada uma.

## US-02 — Refazer o teste

Como usuário cadastrado, quero refazer o teste, para ver se meu perfil ou
minha disponibilidade de modalidade mudou.

- **RF-12**: o sistema deve permitir iniciar uma nova sessão de teste mesmo
  já havendo uma sessão concluída anteriormente para a mesma conta.
- **RN-10**: o histórico deve manter todas as sessões concluídas — uma nova
  sessão nunca sobrescreve ou apaga um resultado anterior.

> Status de implementação: não implementado. Depende do model de usuário
> (EP-05) e de associar `SessaoTeste` a um `usuario_id`.
