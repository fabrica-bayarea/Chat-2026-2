# EP-07 — Administração de Perguntas e Cursos

Permitir manter o catálogo de cursos e o conteúdo do teste sem precisar de
deploy. Depende de [EP-05](EP-05.md) (autenticação/RBAC).

## US-01 — Gerenciar o catálogo de cursos

Como administrador, quero cadastrar, editar e remover cursos do catálogo,
para manter as recomendações atualizadas.

- **RF-13**: o sistema deve prover uma interface CRUD para cursos (nome,
  modalidades aceitas, pesos de afinidade para os 6 perfis).
- **RN-11**: um curso só pode ser salvo se tiver ao menos uma modalidade e
  um peso definido (mesmo que `0.0`) para cada um dos 6 perfis — isso evita
  repetir o bug do catálogo original, em que o curso "Administração" não
  tinha `perfis` e quebraria o cálculo de afinidade.
- **CA-08**: dado que um administrador tenta salvar um curso sem os 6 pesos
  de perfil preenchidos, quando o formulário é submetido, então o sistema
  exibe erro de validação e não salva o curso.

## US-02 — Editar o conteúdo das perguntas

Como administrador, quero editar o texto das perguntas e alternativas do
teste, para corrigir ou atualizar o conteúdo sem alterar código.

- **RF-14**: o sistema deve prover uma interface para editar o texto de
  perguntas e alternativas existentes.
- **RN-12**: a estrutura das 20 perguntas (quantidade, e qual alternativa
  está associada a qual perfil/modalidade) **não** pode ser alterada pela
  interface administrativa nesta fase — apenas o texto exibido. Mudar a
  associação pergunta→perfil exige revisão da lógica de pontuação, não é uma
  operação de conteúdo.
