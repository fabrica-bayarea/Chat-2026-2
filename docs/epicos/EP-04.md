# EP-04 — Chat Livre (Tira-dúvidas via IA)

Permitir conversa livre com o assistente fora do fluxo determinístico do
teste.

## US-01 — Tirar dúvidas livres

Como visitante, quero fazer perguntas livres sobre cursos e carreira, a
qualquer momento da conversa em que não haja uma pergunta do teste pendente.

- **RF-07**: o sistema deve aceitar mensagens de texto livre quando não
  houver uma pergunta do teste aguardando resposta.
- **RN-06**: as respostas do chat livre são geradas por um LLM hospedado
  localmente via Ollama, com um prompt de sistema que restringe o assistente
  ao domínio de orientação vocacional/carreira.
- **CA-06**: dado que o visitante envia uma mensagem livre, quando o backend
  processa, então uma resposta em português é exibida em até 5 segundos
  (RNF-02).

## US-02 — Ser incentivado a fazer o teste

Como visitante que ainda não fez o teste, quero que o assistente me sugira
fazê-lo quando eu perguntar algo relacionado a escolha de curso, para eu
descobrir a funcionalidade principal do produto.

- **RN-07**: se o visitante não tiver uma sessão de teste concluída, o
  assistente deve sugerir o teste ao responder dúvidas genéricas sobre
  escolha de curso ou carreira (via prompt de sistema).

## Requisitos não funcionais

- **RNF-02**: o histórico de mensagens enviado ao LLM a cada chamada deve
  ser limitado às últimas 20 mensagens da sessão, para controlar
  custo/latência.
- **RNF-03**: se o serviço Ollama estiver indisponível, o sistema deve
  responder com uma mensagem de erro amigável, sem quebrar a conversa nem
  expor stacktrace ao visitante.

> Status de implementação: não implementado para o fluxo vocacional. O chat
> conversacional base é tratado no [EP-01](EP-01.md).
